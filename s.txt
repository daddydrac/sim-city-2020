Variables range over those domains. forall means “for every”; exists means “there is at least one”; and, or, not, -> and = have their usual logical meanings. Arithmetic bounds are interpreted over nonnegative integers or finite real-valued measurements. These ASCII forms keep formulas easy to copy into tests in any language. MemberOf(a,g) means that generation g’s immutable manifest references artifact a, directly or through a verified child manifest. It does not require physically duplicating a content-addressed blob. Support(e,p,g) means that assertion e has an accepted evidence record tied to a selected source revision p in g, with valid scope, span and evidence class. SupportsClaim(s,c) means substantive support for claim c, not merely an existing offset; implementing that check requires evaluation and, for difficult claims, review. Before(x,y) is an explicit ordering relation between transition records. It is irreflexive and transitive. A concurrent implementation needs a valid partial order, not a universal total ordering of every worker operation. A state-machine guard operationalizes a predicate, while a persisted receipt provides evidence that a transition happened. Identity, policy, generation and output changing profiles are key dimensions. Validate current controls at the final delivery decision. Retention follows manifests and reader/ rollback pins, not age alone. A formula is a specification, not a deployment proof. A test suite explores a finite set of values and execution schedules. Failed jobs retain receipts and immutable outputs for reconciliation. Retrying a partition does not erase earlier accepted evidence. A failed candidate never changes the active generation. observed_cutoff records what discovery attempted; published_cutoff records what a successfully published generation contains. Those figures do not justify a distributed graph engine or GPU on the serving path by themselves. Enterprise growth can make ingestion, canonicalization, indexing and evaluation expensive long before online hop-1 traversal needs specialized hardware. [S01: D2-STORAGE] [S04] Classify each stage as remote-service-bound, CPU-bound, memory-bandwidth-bound, storage-I/O-bound or coordination-bound. Record work units—bytes, pages, tokens, assertions, edges and requests—so an optimization can be compared without changing semantics. Profile the whole pipeline; an improvement in one kernel may merely expose the next bottleneck. Method 1 · Bounded asynchronous I/O and backpressure Use concurrency to overlap waiting on Document360, S3 or a managed model endpoint. Bounded queues separate fetch, parse and extraction stages. A queue limit in item count is insufficient when a page can be very large; track bytes as well. Acquisition of a permit must account for the request’s estimated token load and remaining deadline, not just the number of threads. In Python, the normal Boto3 client is synchronous. An asyncio implementation must place synchronous calls behind a bounded executor or another explicitly selected adapter; it cannot simply await an ordinary Boto3 method. Cancellation of a coroutine waiting for a thread does not necessarily cancel the remote request. Keep accounting for actual outstanding work until the call terminates, and never release all permits merely because the caller stopped waiting. [R37] [R38] 1. Read a manifest partition, not the entire corpus. 2. Await both queue-byte capacity and a fetch permit. 3. Fetch with a connection/read deadline; validate size while streaming. 4. Hand a bounded buffer or object reference to the parser queue. 5. Release memory only when the downstream owner has accepted it. 6. On cancellation, stop new work and reconcile still-running operations. Acceptance: the maximum observed queued bytes, active calls and resident memory remain within configured bounds during slow downstream responses. A faster source fetcher cannot cause an extraction-worker memory explosion. 10 SOURCE → CONTRACT → IMPLEMENTATION → EVIDENCE WXP / AWS + HPC ENGINEERING TECHNICAL TUTORIAL · 16 SEP 2026 Method 2 · Columnar execution and native CPU kernels Store offline assertions/supports in partitioned Parquet; scan only required columns and relevant partitions with Arrow-compatible readers. Polars provides a streaming execution option, but inspect the actual plan and benchmark operators that may need materialization. Native kernels and vectorized operations can reduce Python object overhead; they do not remove the need to bound joins and sort buffers. [R32] [R33] Use Rust/Rayon when profiling identifies a stable CPU hot loop worth maintaining outside Python. Numba is another option for supported numeric loops, but not a general HTML or arbitrary-object accelerator. In conventional GIL-enabled CPython, pure-Python CPU loops may require process isolation or native code rather than more threads. Validate the actual interpreter and dependency build instead of assuming one concurrency behavior. [R35] [R60] Acceptance: compare byte-for-byte canonical outputs or explicitly defined numerical tolerances against the reference. Record peak memory, spill volume and total time, including serialization across process/language boundaries. Bound native thread pools to avoid multiplying workers by threads until the machine is oversubscribed. Method 3 · External-memory reduction and skew-aware partitioning Canonical graph construction is primarily a join, normalization and support-set reduction problem. Let an assertion identity include source node, relation, target node and applicability qualifiers. Hash-partition by that identity, externally sort each partition and union evidence-support IDs. Duplicate deliveries become duplicate set members rather than duplicate facts. A naive all-pairs entity comparison costs n(n−1)/2 comparisons. At one million nodes that is 499,999,500,000 comparisons. Blocking by type, normalized labels, approved aliases and bounded similarity candidates reduces the search space, but every reduction strategy needs recall tests. Broad “hub” keys can still dominate a partition; use deterministic partial reductions and a final support union, without splitting semantic identity. EMR Serverless Spark becomes relevant when measured joins, shuffle or spills no longer fit a single worker’s envelope. The source explicitly did not require a Spark pipeline; this is a conditional scale extension, not an interpretation of the original architecture. Include job startup, shuffle, object reads and final compaction in the benchmark. [S04] 15 SOURCE → CONTRACT → IMPLEMENTATION → EVIDENCE WXP / AWS + HPC ENGINEERING ENGINEERING FOUNDATIONS TECHNICAL TUTORIAL · 16 SEP 2026 06 · Capacity, latency and cost mathematics First model demand; then choose concurrency Let N be changed pages, ti/to the mean input/output tokens per extraction, R the allocated request limit per minute, Ti/To the allocated input/output token limits per minute, C the active-call cap and L the mean call duration in seconds. A simple throughput upper bound is: pages_per_minute <= min(R, Ti/ti, To/to, 60*C/L) minimum_extraction_minutes >= N / pages_per_minute This is a planning bound under simplified steady-state assumptions, not a service guarantee. It excludes discovery, parsing, throttling, retries, graph reduction, index ingestion and visibility waiting. Reserve foreground demand before allocating background model capacity. Token accounting differs by model/API and must be measured rather than inferred from character counts. [R26] [R38] Calculated example, not an observed quota. Assume 20,000 changed pages, 2,000 input tokens and 400 output tokens per page, 120,000 allocated input tokens/minute, 30,000 output tokens/minute, 100 requests/minute, C=8 and L=5 seconds. The four bounds are 100, 60, 75 and 96 pages/minute. Input tokens limit throughput to 60 pages/ minute; extraction alone requires at least 333.3 minutes, or 5.56 hours. Increasing threads from 8 to 64 does not change that token-bound lower limit.
