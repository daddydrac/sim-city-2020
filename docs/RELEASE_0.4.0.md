# Sim City 2020 0.4.0 — implementation scope

This is an upgraded playable prototype, not completion of every item in the research catalogue and not a claim of matching offline architectural renders.

Implemented: selectable Three.js 0.180.0 renderer with independent WebGL resources, Mercator camera synchronization, instanced geometry, standard materials, tone mapping and atmospheric distance fog; retained deck.gl renderer, Kepler datasets and I3S reference viewer. Expanded architectural details, new destinations, road sidewalks and two-direction illustrative vehicle animation. Existing terrain presets cover approximately 16.4 × 12.3 km; source terrain remains editable and CSV/GeoJSON imports remain supported. Existing ten-phase development, utilities, climate approximations, continuous strokes, parking structures and satellite animation remain.

Added SQLite named checkpoints through a same-origin local Python service, with transactional inserts and Docker volume persistence. Each checkpoint is independent; selecting Save new checkpoint never overwrites another. Existing browser autosave and JSON downloads remain independent recovery routes. SQLite owns manual checkpoints, not every simulation frame. Uploaded GLBs remain session-only. Do not delete Docker volumes unless you intend to delete checkpoints.

Added residential, commercial, industrial, tourism and space tax rates; land-value-sensitive surcharge; per-sector ledger; modeled toll receipts; population-weighted approval; slowly changing infrastructure condition. Condition is currently an indicator plus maintenance response, not a full failure/path-capacity model. Toll volume is a price-sensitive estimate, not individually charged simulated cars. Space tax is charged on satellite contract receipts. Property taxes reconcile to displayed parcel receipts.

Seven new synthesized population compositions vary meter, tempo, chord progression, melody and instrument family. Sound effects use differentiated filtered noise/oscillator cues for paving, excavation, pipes, wiring and UI actions. These remain synthetic prototype audio, not professional recorded effects. Independent volume controls persist across cities. A 30-second population dwell triggers an eight-second fade. This release does not yet implement the full research audio playlist/hysteresis design.

Three.js handles the built-in city scene and terrain. Switch to deck.gl for native heatmaps, hexagons, timestamped TripsLayer analytics, uploaded GLB scenegraphs, and I3S reference scenes. The renderer selector reloads the application; Continue saved city restores the browser autosave. Both renderers require functioning WebGL. Integrated graphics is supported in principle; a GPU-free canvas fallback is not implemented. Software rendering depends on browser/driver support and may be slow.

Remaining research roadmap: high-quality authored PBR building collections, physically based water reflections, full weather atmosphere, ray tracing, curved lane-graph road/freeway editing, traffic assignments, pedestrian routing, component-level hydraulic/electric solvers, calibrated climate physics, persistent imported model libraries, scenario history and causal optimizers. Do not interpret animated vehicles or utility pulses as solved physical flows. The Ferris wheel is currently a static buildable landmark.
